# SketchReport - Sistema de Gestión de Reportes y Multimedia

## Descripción
SketchReport es una aplicación web desarrollada en Laravel que permite gestionar reportes y archivos multimedia de manera eficiente. El sistema cuenta con una interfaz moderna y responsiva construida con Tailwind CSS.

## Características Implementadas
- Sistema de autenticación de usuarios
- Gestión de reportes (CRUD)
- Gestión de archivos multimedia
- Interfaz de usuario moderna y responsiva
- Dashboard con vista de últimos reportes y archivos multimedia
- Perfil de usuario con gestión de información personal
- Sistema de suscripciones
- Sistema de búsqueda global
- Filtrado de reportes y multimedia
- Gestión de teléfono en perfil de usuario
- Modal de confirmación para eliminación de cuenta

## Requisitos del Sistema
- PHP >= 8.1
- Composer
- Node.js y NPM
- MySQL/MariaDB
- Servidor web (Apache/Nginx)
